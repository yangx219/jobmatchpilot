# Changelog

## 0.1.0 — version portfolio

- identité publique JobMatchPilot ;
- parcours de découverte d’offres en trois étapes ;
- intégration Greenhouse, Lever, Ashby et JobSpy optionnel ;
- normalisation, filtrage et déduplication des offres ;
- file PostgreSQL persistante et worker avec reprise après erreur ;
- regroupement des tâches avec les activités ;
- regroupement des entretiens avec la banque de questions ;
- interface français, anglais et chinois ;
- améliorations responsive et mise à jour des tests.

La base open source provient de JobSync v1.2.0. Son historique antérieur est disponible dans le [dépôt d’origine](https://github.com/gsync/jobsync).
